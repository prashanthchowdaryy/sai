# Tanisha – personal surprise website

Open `index.html` in a browser (or host the folder anywhere static, e.g. GitHub Pages / Netlify).

## Assets (put in `assets/`)
| File | What it is |
|---|---|
| `tanisha-message.mp4` | Your video (already included from Tanisha.mp4) |
| `video-poster.jpg` | Optional thumbnail for the video |
| `puttaparthi-hero.jpg` | Sunset Prasanthi Nilayam photo, landscape, ~1920px, under 400 KB |
| `temple-background.jpg` | Landscape for the final section |
| `sai-baba-authentic.jpg` | Optional. A genuine photograph only; the letter looks fine without it |
| `devotional-music.mp3` | Royalty-free instrumental (flute, tanpura, veena) |

Missing images fall back to a warm sunset gradient; the portrait simply disappears.
Use only licensed photos and music. Do not use AI-generated portraits of Sai Baba.

## Behaviour
- Nothing plays automatically. Music starts only via the round button (volume 25%, fades).
- When the video plays, music fades out; it fades back in afterwards if it was on.
- Edit text in `index.html`; colours are variables at the top of `style.css`.
